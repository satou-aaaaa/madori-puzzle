# 間取りパズル

住む人の希望（「キッチンはリビングのとなり」「寝室は北側がいい」など）を全部かなえるように、部屋を並べる1日3軒のパズル。答えは1つです。

- 遊ぶ: https://satou-aaaaa.github.io/madori-puzzle/
- 下の部屋を押して選び、家のますを押すと置けます。置いた部屋を押すと選べて、別のますを押すと動きます（そこにある部屋と入れかわります）。もう一度押すと台に戻ります。
- 上が北です。「となり」は壁でくっついている部屋（ななめは入りません）。「北どなり」は真上の部屋です。
- 今日の3軒（平屋・二世帯・注文住宅）はだれでも同じで1日1回。家の種類ごとに新しい希望の種類が増えます。上級（希望の多い2軒・かなったかどうかは完成まで出ない・ヒントなし）、練習、とことん（降りるまで次々に建てる）があり、はじめての日から全部遊べます。回数の制限やチケットはありません。時間制限はありません。部屋を一度も動かさず、ヒントなしで完成すると「書き直しなし」。実績と遊んだ日のカレンダーがあり、過去7日の取りこぼした日はあとから遊べます（連続の日には数えません）。
- 記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（間取りは入りません）。

## 開発

```bash
bash scripts/setup.sh   # 最初に一度
node qa/run.mjs         # 検査（CI と同じ）
node tools/gen-levels.cjs   # data.js を作り直すとき（1分ほど）
```
